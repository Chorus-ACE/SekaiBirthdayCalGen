# BirthdayCalGen

This command line tool generates .ics files for character birthdays.

To build this tool, you need to get [DoriKit](https://github.com/Greatdori/DoriKit)
first, and create a xcworkspace with DoriKit and this project.
Run the command below:

```sh
mkdir Greatdori
cd Greatdori
git clone https://github.com/Greatdori/DoriKit.git
git clone https://github.com/Greatdori/BirthdayCalGen.git
```

Create a xcworkspace in `Greatdori` directory,
drag `DoriKit.xcodeproj` and `BirthdayCalGen.xcodeproj`
into the workspace. Then this project can be built in Xcode.
